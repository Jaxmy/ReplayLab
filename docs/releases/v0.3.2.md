# Replay Lab v0.3.2

- 新行情推进后自动跟随最新 K 线，手动单步、推进和播放均适用；拖动或缩放后再次推进会恢复跟随并保留横向缩放宽度。
- 指标名称、参数和最新读数移到图表下方，价格轴留给主 K 线，右侧保留空白以避免遮挡。
- 初始化加入分钟、小时、日及以上的开始周期，按资产基础数据自动限制可选项。
- 开始前默认显示同周期的 300 根已收盘 K 线，可设置 1–5000 根。历史不足时显示实际数量；周/月等未结束周期不会提前显示。
- 历史预览按月聚合读取，恢复时校验内容；保留旧版记录兼容性。
- 延续 0.3.1 的指标配置、批量记录删除、策略回测、报告导出等功能。

下载下方 `Replay-Lab-v0.3.2-windows-x64.zip`，解压到有写入权限的目录并运行 `setup.ps1`。需要 Windows 10/11、Python 3.12/3.13、Node.js 22 或更新版本。VS Code 安装 `vscode/local-replay-lab-0.3.2.vsix` 后执行 Developer: Reload Window。

升级前运行 `stop.ps1` 保存并停止旧服务。数据、记录和报告保存在项目目录；发布包不包含个人行情、记录或令牌。浏览器和 VS Code 共用界面与本地 API。显示高周期时，交易仍按基础 K 线时钟处理。

验证：47 项 Python 测试通过；浏览器 HTTP 和 VS Code 桥接两种模式各完成 90 次 API 请求回归；真实图表验证了 300 根小时线、外置指标读数及拖动后单步跟随。

同名 `.zip.sha256` 文件可用于校验下载。详细安装、数据补充和策略使用方法见 README。
