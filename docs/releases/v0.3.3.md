# Replay Lab v0.3.3

修复 Windows CMD 启动网页时报 `UnexpectedToken`、字符串缺少终止符等错误。

`start-browser.cmd` 调用 Windows PowerShell 5.1；此前含中文的无 BOM UTF-8 脚本会被系统代码页错误解码。此次将启动、停止、安装脚本统一保存为带 BOM 的 UTF-8，并在 Release 发布前使用 Windows PowerShell 5.1 检查编码与语法。

下载 ZIP 解压后运行 `setup.ps1`，之后双击 `start-browser.cmd`。已有安装可更新项目文件；历史行情、记录与报告继续保存在各自目录。VS Code 用户安装新的 `vscode/local-replay-lab-0.3.3.vsix` 后重载窗口。兼容 0.3.2 及之前支持的历史记录。

附带 `.zip.sha256` 下载校验文件。图表、模拟交易、策略和历史预览功能沿用 0.3.2。
